# 현대전 반영 전쟁 모듈 설계안

`world-leader.html` 전쟁 모듈을 현대전 자료에 맞춰 다시 짜기 위한 설계안이다. 코드는 포함하지 않는다.
수치에 붙은 표시: **[검증]** 신뢰할 만한 출처 2곳 이상 또는 1차 기관 자료로 확인, **[보도]** 언론 보도·2차 인용만 확인, **[추정]** 검증하지 못했거나 이 설계에서 정한 게임 수치.

## 1. 현재 모델의 한계

| 항목 | 진단 |
|---|---|
| 단일 군사력 | MIL 하나로 지상·항공·방공·해군을 뭉뚱그려, 인도·파키스탄식 미사일·드론 교환전이 지상전처럼 계산된다. |
| 전선 변동 폭 | `(p−0.5)×130 ± 20`이라 한 분기에 전선이 ±50씩 움직인다. 러시아·우크라이나 2025년 연간 영토 변화(국토의 약 0.94%)를 재현할 수 없다. |
| 시간 단위 | 최소 단위가 분기라 4~12일 전쟁도 한 분기 전체 비용을 낸다. |
| 재고·생산 | 탄약·요격미사일 재고가 없어 지속력 차이가 결과에 안 들어간다. |
| 방어 이점 | 고착될수록 커지는 방어 보너스가 없다. 전장 투명화로 방어가 유리해진 현상을 못 담는다. |
| 전술 고정 | 같은 전술을 반복해도 효과가 그대로다. 상대 적응이 없다. |
| 해상·상륙 | 섬나라도 지상 인접처럼 점령된다. 해상 통제와 상륙 조건이 없다. |
| 사상자 규모 | 분기 사상자가 수천~수만 명 수준이라 연 40만 명대 소모전을 재현하지 못한다. |
| 종전·재발 | 휴전 뒤 위반·재발이 없다. 태국·캄보디아처럼 휴전 후 교전이 재발하는 경우를 못 담는다. |
| 수적 우위 | 전력비가 선형이라 병력 2배가 효과 2배로 들어간다. |

## 2. 새 상태 구조

### 2.1 국가 군사 능력 `CAP[iso]` (정적, 0~100)

| 필드 | 의미 |
|---|---|
| `gnd` | 지상군(병력·기갑·포병 종합) |
| `air` | 항공·미사일 타격력(전투기, 탄도·순항미사일, 장거리 드론 포함) |
| `ad` | 방공(층위별 요격 체계 종합) |
| `nav` | 해군(수상함·잠수함·상륙 능력) |
| `uas` | 드론·전자전(전술 드론, 무인수상정, 재밍) |
| `ind` | 방산 생산력(탄약·드론·요격미사일 보충 속도) |
| `ammo0` | 개전 시 탄약 재고(전면전 강도 기준 몇 분기분인지를 0~100으로 환산) |
| `intc0` | 개전 시 요격미사일 재고(0~100) |

## 3. 수식과 상수표

### 3.1 전쟁 유형 결정 (개전 시)

순서대로 처음 맞는 규칙을 쓴다.

1. 지상 국경이 없음(`NEIGH`에 상대가 없거나 `island`) → 목표가 `regime`·`humbl`이고 공격측 `nav ≥ 60`이면 `amph`, 아니면 `strike`.
2. 양측 모두 `nuke` → `strike` 또는 `border`(목표 `border`면 `border`, 그 외 `strike`). 확전 상한 `rung ≤ 2`, 4.8절의 핵 억지 가산 적용.
3. 목표 `border` → `border`.
4. 목표 `regime`·`humbl`이고 공격측 지상 유효전력이 방어측의 1.3배 이상 → `total`. 아니면 `border`로 시작하고 확전으로만 `total`에 간다.

### 3.2 확전 사다리

| 단계 | 이름 | 분기당 비용(공격측 기준, 방어측은 절반) | 국제 반응 | 핵 위험 지수 NR |
|---|---|---|---|---|
| 0 | 위기 | 없음 | 중재 제안 확률 +0.25 | 0 |
| 1 | 국경 충돌·제한 타격 | `ec −1, fis −2` | 제재 확률 0.1 | 0.05 |
| 2 | 원거리 타격전(군사기지·기반시설) | `ec −2, fis −4, env −1` | 제재 확률 0.3, `intl +15` | 0.15 |
| 3 | 전면전·상륙전 | `ec −3~−5, fis −6, env −2` | 제재 확률 0.6, `intl +25` | 0.3 |
| 4 | 전략 위협 국면 | 3단계와 같음 + `ap` 변동 2배 | `intl +40`, 강대국 중재 개입 | 0.6 |

- 핵보유국이 끼면 NR에 1.5를 곱한다. NR은 플레이어 선택지가 아니라 종전 위험률(4.7)과 경고 사건 발생률에만 쓰인다. 핵 사용 선택지는 만들지 않는다.
- 플레이어는 매 분기 "확전 / 유지 / 완화"를 고른다(결정 1). AI는 `p_eff > 0.6`이고 재고가 50 이상이면 확전, 지지도가 30 이하이면 완화한다.

### 3.3 단기전의 일 단위 계산

`strike`, `border`, 그리고 `amph`의 첫 분기는 한 분기를 90일로 쪼개 하루씩 계산하고, 종전 위험률(4.7)에 걸리면 그날 끝낸다. 비용은 `days/90`만큼만 낸다.

하루 교환:

```
V_a  = (air_a × 0.6 + uas_a × 0.4) × R[rung] / 10        공격 물량
r_d  = ad_d / (ad_d + 0.8 × V_a) × min(1, stk_d.intc / 10)  요격률
D_d += V_a × (1 − r_d) × 0.15                               피해 누계(dmg)
stk_d.intc −= V_a × r_d × 0.25                              요격미사일 소모
stk_a.ammo −= V_a × 0.05
R = [0, 0.6, 1.0, 1.4, 1.4]                                 단계 배율
```

양측이 서로 공격하므로 위 식을 쌍방향으로 매일 적용한다.

### 3.4 분기 전투력 (지상·전면전)

수적 우위는 체감하도록 지수 0.6을 쓴다(Dupuy식 질적 계수 강조).

```
E = (gnd_eff)^0.6 × Q × S
gnd_eff = gnd × (1 + MOB[mob]) + Σ 동맹 gnd × 0.3
Q = (1 + 0.07 × 장군 능력치 + TAC.m × nov[tac]) × 사기 × 보급 × 드론
  사기 = 0.5 + 0.5 × sup / 100
  보급 = fis < 20 ? 0.75 : fis < 40 ? 0.9 : 1      (병참통은 1 고정)
  드론 = 1 + 0.3 × (uas_me − uas_foe) / 100
S = min(1, stk.ammo / 소모량)^0.5                    재고 계수
p = E_me / (E_me + E_foe)
MOB = [0, 0.15, 0.35, 0.5]
```

### 3.5 영토 변화, 고착, 돌파

```
Δterr(%) = 15 × (p − 0.5) × (1 − ent)            주 인구 가중 영토 변화
ent      += |Δterr| < 1 ? 0.2 : −0.15            고착될수록 커짐, 0~0.9
방어측 Q  ×= 1 + 0.4 × ent                        진지 방어 보너스
소모전 국면(ent ≥ 0.5)에서는 |Δterr| ≤ 1.0 (분기당 국토 1% 미만)
```

- 국면 전환: `ent ≥ 0.5`면 `attrition`, 돌파가 나면 `maneuver`로 돌아간다.
- **돌파**(드문 사건): 분기마다 `P = max(0, p − 0.7) × 0.6 + (방어측 ammo < 15 ? 0.15 : 0) + (방어측 sup < 25 ? 0.1 : 0)`. 성공하면 `Δterr += 10~25`, `ent = 0.1`.
- 점령 주 선택은 기존 방식(국경에서 가까운 주부터)을 유지하되 개수 대신 누적 인구 비율이 `terr`에 닿을 때까지 채운다.
- 수도 주가 점령되면 방어측 `sup −30`.

### 3.6 전술 신선도(상대 적응)

```
사용한 전술 : nov[t] = max(0.3, nov[t] × 0.7)
안 쓴 전술  : nov[t] = min(1, nov[t] + 0.15)
```

같은 전술을 3분기 연속 쓰면 가산 효과가 약 1/3로 준다. AI도 같은 규칙을 적용받는다.

### 3.7 재고 소비와 보충

| 유형 | 분기 탄약 소모(강도 1 기준) | 비고 |
|---|---|---|
| `strike` | 0.1 (요격미사일은 3.3 식으로 일 단위 소모) | |
| `border` | 0.3 | |
| `total` | 1.0 | 소모전 국면은 1.2 |
| `amph` | 0.8 + 상륙 시도마다 0.3 | |

```
탄약 보충/분기   = ind / 100 × 8 × (1 + 0.15 × 전시경제분기수, 최대 +45%) + 동맹 원조
요격 보충/분기   = ind / 100 × 1.5          (THAAD 사례: 소모분 보충 3~8년)
분기 소모량      = 소모 계수 × (gnd_eff / 10)
```

- 근거: 러시아 2025년 생산 추정 약 700만 발(포·박격포·전차·로켓탄 합계, 에스토니아 정보당국)[보도]과 2024년 미국+유럽 약 120만 발(DGAP)[보도]의 격차를 `ind` 차이(85 대 50~65)와 전시경제 가산으로 낸다.
- 요격미사일: 이스라엘·이란 12일 전쟁에서 미국이 THAAD 재고의 약 14~25%를 썼다는 보도[보도]. 1발 약 1,270만 달러(MDA FY2025 예산 기준 보도)[보도]. 보충 3~8년[보도]. 그래서 요격 보충은 탄약보다 한 자릿수 느리게 둔다.

### 3.8 해상 통제와 상륙

```
sea = (nav_me − nav_foe) − 0.5 × uas_foe × 해협계수 − 0.3 × air_foe × (1 − ad_me/100)
해협계수 = 좁은 해역(연안 300km 안) 1.0, 대양 0.3
```

- 우크라이나 무인수상정 사례는 좁은 해역에서 함대 열세국이 해상 거부를 할 수 있음을 보여준다. 그래서 `uas`가 좁은 해역에서만 크게 작용하게 한다.
- 상륙 시도 조건: `sea ≥ +40`이고 `air_me / (air_me + ad_foe) ≥ 0.6`.
- 상륙 성공 확률(시도당): `P = 0.15 + 0.004 × (sea − 40) + 0.3 × (p − 0.5)`, 상한 0.55. 방어측 동맹 참전 시 `sea −25`, `p`에 동맹 반영.
- 실패하면 `casT.me += 상륙 병력 손실(10~40천)`, `nav −10`, `sup −10`. 성공하면 `type`을 `total`로 바꾸고 교두보로 `terr += 3`.

### 3.9 사상자

```
casQ(천 명) = K[type] × 강도 × (gnd_eff_me + gnd_eff_foe) / 2 × (1 + |Δterr| / 5) × 전술 cas 배율 × (1 + uas_상대 / 200)
K = { strike: 0.02, border: 0.2, total: 1.6, amph: 2.0 }
측별 분배: 공격 명령 측 0.55, 방어 명령 측 0.45 (양측 공세면 0.5씩)
```

`total`·`attrition` 국면에서 `gnd_eff` 약 90대 쌍이면 분기 합계가 대략 150~200천 명이 되도록 K를 맞춘다. 러시아 2025년 사상자 약 41.5만 명(영국 국방정보 추정)[보도]이 한쪽 연간 값의 기준이다.

### 3.10 전쟁 점수(`front`)

```
front = clamp(3 × terr + 0.4 × (dmg.foe − dmg.me) + 0.3 × (stk.me.ammo − stk.foe.ammo) + (sea 해당 시 0.2 × sea), −100, 100)
```

기존 협상 조건(`front ≥ 30` 목표 달성, `≤ −30` 양보)은 그대로 쓴다.

## 4. 기존 요소 재정의

### 4.1 전술 → 영역

| 전술 | 명령 | 주 영향 영역 | 효과 |
|---|---|---|---|
| 정면 돌파 | 공세 | 지상 | `TAC.m +0.12`, 탄약 소모 ×1.3, 사상자 ×1.4 |
| 측면 기동 | 공세 | 지상·드론 | `m +0.08`, 결과 편차 ×1.5, `uas` 우세면 `m +0.05` |
| 포위 섬멸 | 공세 | 지상 | 성공률 `0.2 + 0.1×공격력 − 0.3×ent`(고착 시 어려움), 성공 `m +0.3`·돌파 확률 +0.15 |
| 종심 방어 | 방어 | 지상·방공 | `m +0.18`, `ent` 증가 +0.1, 요격률 +0.05 |
| 소모전 | 방어 | 재고 | 상대 탄약 소모 ×1.3, 상대 지지도 −5, 우리 지지도 −3 |
| 방어 후 역습 | 방어 | 지상 | 성공률 `0.15 + 0.1×방어력`, 성공 `m +0.25` |

원거리 타격전(`strike`)에서는 지상 전술 대신 같은 버튼 자리에 "기지 타격 / 기반시설 타격 / 방공 집중" 3가지를 쓴다. 민간인 표적은 선택지에 없고, 민간 피해는 `dmg`와 사건 카드로만 나온다.

### 4.2 장군 특성 → 영역

| 특성 | 영향 |
|---|---|
| 과감 | 공세 능력 +1, 사상자 ×1.15, 돌파 확률 +0.05 |
| 신중 | 방어 능력 +1, `ent` 증가 +0.05 |
| 병참통 | 보급 계수 1 고정, 탄약 소모 ×0.85 |
| 백전노장 | 편차 ×0.7, 전술 신선도 감소 ×0.85(적응이 덜 됨) |

### 4.3 전작권

| 상태 | 결정 2(전술) | 그 밖 |
|---|---|---|
| 보유 | 플레이어가 고른다 | 확전 결정(결정 1)도 직접 |
| 미보유(한국 기본) | 연합사령관 AI가 고른다(능력치 기반 `aiPlan`) | 확전 결정 1 중 "확전"은 동맹 협의 필요. 승인 확률 `0.4 + rel(USA)/250`. 연합 지휘라 `nav`·`air`·`ad`에 미국 전력 일부(0.3) 가산 |

## 5. 국내 영향 (기존 지표 변화량)

| 요소 | 지표 변화(분기당) | 비고 |

## 6. 종전

### 6.1 협상 수락 확률

```
x = a0[조건] + 0.03 × front_proposer
           + 0.04 × (60 − sup_receiver)
           + 1.2 × (1 − S_receiver)                 재고 고갈일수록 수락
           + 0.8 × clamp(casQ_now / casQ_prev − 1, −1, 1)   사상자 증가 추세
           + 0.5 × 중재국 유무
           + 0.01 × intl
P = 1 / (1 + e^(−x))
a0 = { 현상유지 −0.5, 상대 양보 요구 −2.0, 우리 양보 +3.0 }
```

### 6.2 자동 종전 위험률

```
단기전(일 단위) h_day = h0[type] × (1 + 0.5 × 중재) × (1 + NR) × (1 + 재고고갈) × (1 + intl/100)
  h0 = { strike: 0.10, border: 0.14 }
  재고고갈 = 어느 쪽이든 intc 또는 ammo < 15면 1, 아니면 0
장기전(분기) h_q = 0.06 + 0.4 × max(0, 0.4 − min(sup)/100) + 0.15 × 재고고갈 + NR × 0.2
```

`h0 = 0.10/일`이면 중앙값 약 7일, 0.14면 약 5일이다. 인도·파키스탄(약 4일), 태국·캄보디아(5일), 이스라엘·이란(12일)의 범위를 이 값과 NR·재고 가산으로 맞춘다.

### 6.3 휴전 위반과 재발

```
위반 확률/분기 v = 0.3 × (1 − settled) × (HOSTILE ≤ −50 ? 1.3 : 1) × (1 − 0.5 × 중재 보장)
재발 확률/분기   = 0.12 + 0.08 × 위반 누적(최대 3) − (settled ? 0.1 : 0)
```

- 위반이 일어나면 관계 −5, `ap ±1` 로그만 남긴다. 재발하면 같은 상대·같은 유형으로 `rung 1`에서 다시 시작한다.
- 국경 확정(`settled`)은 강화 협상에서 "국경 획정 위원회" 조건을 받아들일 때 켜진다(행동 1회).
- 태국·캄보디아: 7월 28일 휴전 직후부터 위반 주장이 나왔고 12월 8일 교전이 재발했다(약 2분기)[검증]. 위 식으로 4분기 안 재발 누적 확률이 약 45~55%가 되게 맞춘다.

### 8.1 simWar 확장과 확인 방법

```
simWar(a, b, { n = 5000, goal, opcon, allies: [], tac, rung })
반환: { 결과 비율, 일수 분위(10/50/90%), 분기 분위, terr 분위, 양측 casT 분위, 종료 시 재고, 4분기 안 재발률 }
```

1. 시나리오마다 n = 5,000으로 돌려 위 표의 목표 구간에 드는지 확인한다.
2. 민감도: `h0`, `15(Δterr 계수)`, `0.2(ent 증가)`, `0.6(체감 지수)`, `0.7(신선도 감소)`, `0.25(요격 소모)`, `K[total]`를 하나씩 ±20% 바꿔 같은 시나리오를 돌린다. 목표 지표가 25% 넘게 움직이는 계수는 "취약"으로 표시하고, 해당 시나리오는 그 계수 대신 시나리오 전용 보정(예: 핵 억지 가산)으로 맞춘다.
3. 회귀 확인: 기존 결말(안보 붕괴, 패전 실각)이 나오는 빈도가 개편 전후 ±30% 안에 드는지 본다.

## 10. 위험 요소와 남은 질문

- **면적 데이터 없음:** 영토 변화를 주 인구 가중으로 계산하므로 우크라이나 동부처럼 인구가 적은 넓은 지역의 변화가 작게 잡힌다. atlas에 주 면적을 추가할지 결정이 필요하다.
- **해협 판정:** "좁은 해역" 여부를 수도 간 거리로 근사해야 한다. 흑해·대만해협·지중해 동부는 손으로 지정하는 편이 안전하다.
- **CAP 표의 신뢰도:** 30개국 수치는 공개 순위와 보도를 종합한 게임 근사치다. 특히 `ammo0`, `intc0`는 공개 자료가 거의 없어 전부 추정이다.
- **진행 중 분쟁의 중립성:** 러시아·우크라이나 보정 목표에 한쪽 사상자 추정치만 쓰면 편향될 수 있다. 화면에는 양측 모두 "추정"으로 표기하고 특정 측 발표만 인용하지 않는다.
- **드론 사상자 비율:** 70~80% 주장은 군 사상자 기준으로 검증되지 않았다. 그래서 드론은 별도 사상자 비율이 아니라 `uas` 우세에 따른 전투력·사상자 배율로만 넣는다.
- **복잡도:** 결정은 3개로 묶었지만 내부 상태가 크게 늘어난다. 저장 크기와 리더보드 호환(기존 점수식)에 영향이 없는지 확인해야 한다.
- **남은 질문:** (1) 상륙전 이후 장기 점령을 지상전과 같은 식으로 처리할지 (2) 강대국끼리의 전쟁(미·중)을 플레이어 선택으로 허용할지 (3) 전시경제 전환을 되돌릴 수 있게 할지.
